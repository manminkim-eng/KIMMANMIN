이용 안내 — 이 도구들은 설계·검토 업무를 돕는 참고용 계산 도구입니다. 결과는 관계 법령·기준(적용 기준일)과 대조해 사용자가 최종 검토해 주세요. 인허가 도서 등에 쓴 결과의 책임은 사용자에게 있습니다. 입력값은 사용하는 기기에만 저장되며 MANMIN이 따로 수집하지 않습니다.

설치 방법

Android 태블릿·휴대폰(갤럭시 등) 공통 — Chrome 기준

  1. 도구 페이지 열기 — 데스크탑 화면의 QR을 카메라로 스캔하거나, 이 페이지를 폰에서 열어 카드의 열기 · 설치를 누릅니다.
  2. Chrome인지 확인 — 카카오톡·네이버 앱 안에서 열렸다면 오른쪽 위 ⋮ → 다른 브라우저로 열기 → Chrome. 앱 안 브라우저에서는 설치가 되지 않습니다.
  3. 설치 — 화면이 다 뜬 뒤 오른쪽 위 ⋮ → 홈 화면에 추가 → 설치 (Chrome 판에 따라 메뉴 이름이 앱 설치로 나옵니다). 아래쪽에 설치 띠가 뜨면 그것을 눌러도 됩니다.
  4. 홈 화면에서 확인 — 아이콘 이름은 카드의 홈 화면 이름(예: 업무대가·소방포털)으로 생깁니다. 눌렀을 때 주소창 없이 열리면 정상 설치입니다.
  5. 오프라인 준비 — 설치 직후 인터넷이 될 때 한 번 실행해 두면 계산 화면이 저장되어 현장(인터넷 없음)에서도 열립니다. 단, 법규 검색·포털의 다른 도구 이동처럼 새 자료를 불러오는 기능은 인터넷이 필요합니다.
순서 추천 — 0번 시작 페이지 3종 → 1번 공종 포털 4종을 먼저 설치하고, 나머지는 자주 쓰는 도구만 골라 설치하세요. 포털 안에서도 각 계산서로 들어갈 수 있습니다.
  1. 삼성 인터넷으로 도구 페이지를 엽니다.
  2. 주소창 오른쪽에 설치 아이콘(⬇ 또는 앱 모양)이 보이면 누르고 설치.
  3. 아이콘이 없으면 아래쪽 ≡ 메뉴 → + 현재 페이지 추가 → 홈 화면.
삼성 인터넷에서 설치하면 그 앱은 삼성 인터넷으로 열립니다. 기기마다 한 브라우저(Chrome 권장)로 통일하면 관리가 쉽습니다.
  1. Safari로 도구 페이지를 엽니다(카톡에서 열렸다면 오른쪽 아래 공유 → Safari로 열기).
  2. 아래쪽 공유 단추(□↑) → 홈 화면에 추가 → 오른쪽 위 추가.
  3. 홈 화면 아이콘으로 열면 주소창 없이 앱처럼 열립니다.
아이폰은 몇 주 동안 열지 않은 앱의 저장 자료를 비울 수 있습니다. 현장에 가기 전 인터넷이 될 때 한 번 열어 두세요.
  1. Chrome 또는 Edge로 도구 페이지를 엽니다(카드의 열기 · 설치).
  2. 주소창 오른쪽 끝의 설치 아이콘(모니터+⬇) → 설치. 또는 ⋮ → 전송, 공유 및 저장 → 페이지를 앱으로 설치(Edge: … → 앱 → 이 사이트를 앱으로 설치).
  3. 바탕화면·시작 메뉴에 MANMIN 업무대가처럼 MANMIN + 홈 화면 이름으로 생깁니다.
설치 메뉴가 안 보여요
① 카카오톡·네이버 앱 안 브라우저인지 확인 → Chrome으로 열기 ② 시크릿 탭이면 일반 탭으로 ③ Play 스토어에서 Chrome 업데이트 ④ 화면이 다 뜬 뒤(5초쯤) 다시 ⋮ 메뉴 확인.
아이콘을 누르면 주소창이 있는 창으로 열려요
"앱"이 아니라 "바로가기"로 만들어진 경우입니다. 아이콘을 길게 눌러 제거한 뒤, 홈 화면에 추가 대화상자에서 설치를 골라 다시 만드세요.
고친 내용이 반영 안 되고 옛 화면이 나와요
인터넷이 될 때 앱을 열고 → 완전히 닫았다가(최근 앱에서 밀어 닫기) → 다시 엽니다. 저장된 화면이 새것으로 바뀌는 데 한 번 더 걸릴 수 있습니다.
사이트 데이터 삭제는 조심
42개 도구가 모두 같은 주소(manminkim-eng.github.io)를 써서, Chrome 설정에서 이 사이트의 저장 데이터를 지우면 모든 도구의 입력값·오프라인 저장이 함께 지워집니다. 위 방법으로 안 될 때만 쓰세요.
QR이 잘 안 읽혀요
모니터 밝기를 올리고 20~30cm 거리에서 QR 하나만 화면에 들어오게 찍습니다. 기본 카메라에서 안 되면 Google 렌즈(Chrome 주소창의 카메라 아이콘)를 쓰세요.
폰에서 QR은 어떻게 쓰나요
폰 화면의 QR은 폰이 직접 찍을 수 없습니다. 폰에서는 열기 · 설치 단추를 쓰고, 위쪽 QR 보기를 켜면 폰 화면을 태블릿에 보여 주어 태블릿으로 스캔할 수도 있습니다.
필요한 권한
설치에 따로 허용할 권한은 없습니다(카메라는 QR 스캔에만). 런처가 "홈 화면에 추가 허용"을 물으면 허용하세요. 계산서 PDF 저장은 앱 안 인쇄 단추 → PDF로 저장.
앱 지우기
홈 화면 아이콘을 길게 누름 → 제거(또는 앱 정보 → 제거). 다른 도구에는 영향이 없습니다.
